= MetroCluster を使用した VCF ワークロードドメインのストレッチクラスタの構成
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
このユースケースでは、FC、iSCSI、NVMe-oF、NFSv3、またはNFSv4.1をプライマリデータストアとして使用するONTAP MetroClusterを用いて、VMware Cloud Foundation (VCF) ワークロードドメイン向けのストレッチクラスタを構成する手順を概説します。VCFは、お客様のニーズに基づいた柔軟な導入オプションを提供します。VCF Opsツールは、新しいVCFワークロードドメインをデプロイするか、既存のvSphere環境をVCFワークロードドメインにインポートするために使用します。このドキュメントでは、MetroClusterの部分に焦点を当て、導入手順に基づいて他のドキュメントを参照します。

image:vmw-vcf-vmsc-viwld-mcc-001.png["vMSCを使用したVCFワークロード ドメイン、幅=500"]



[[introduction]]
== はじめに

このソリューションでは、ONTAP MetroClusterをプリンシパルデータストアとして使用したストレッチド VCF ワークロード ドメインの実装方法を説明します。MetroClusterを使用すると、ONTAPクラスター上で実行されているすべてのワークロードに対して高可用性ソリューションをデプロイできます。ワークロードに特化した高可用性ソリューションを導入する必要がある場合は、SnapMirrorアクティブ同期（SANおよびNAS）の使用を検討してください。SnapMirrorアクティブ同期（SAN）は整合性グループレベルで動作しますが、SnapMirrorアクティブ同期（NAS）はSVMレベルで動作します。詳細については、link:vmw-vcf-vmsc-viwld-smas.html["VCFワークロードドメイン向けのストレッチクラスタをSnapMirror Active Sync（SAN および NAS）を使用して構成する"]を参照してください。



[[prerequisites]]
== 前提条件

このシナリオには、次のコンポーネントと構成が必要です。

* サポートされているONTAP MetroCluster構成
* ストレージ仮想マシン（SVM）は、優先ストレージ プロトコルで設定されています。
* ストレージトラフィックを伝送するために論理インターフェース（LIF）が作成され、SVMに関連付けられています。




[[high-level-overview]]
== 概要

MetroCluster は、集約レベルで処理されるワークロードに対して高可用性ソリューションを提供します。SVM は、MetroCluster のいずれかの障害ドメインでアクティブになります。

[[deployment-steps-for-greenfield-vcf-workload-domain-with-metrocluster]]
== グリーンフィールド VCF ワークロードドメインと MetroCluster の導入手順

グリーンフィールド展開（既存の VCF コンポーネントを使用しない新規展開）の場合、ワークロードドメインの展開には VCF Ops ツールが使用されます。このシナリオでは、FC および NFSv3 上の VMFS がサポートされています。

VMFS on FC の場合、詳細については link:vmw-vcf-viwld-principal-fc.html["VCFワークロードドメインとFCベースのVMFSデータストア（ONTAPをプリンシパルストレージとして使用）"] を参照してください。NFSv3 の場合、詳細については link:vmw-vcf-viwld-principal-nfs.html["NFSv3データストアを備えたVCFワークロードドメイン（主要なストレージとしてONTAP上）"] を参照してください。



[[deployment-steps-for-brownfield-vcf-workload-domain-with-metrocluster]]
== ブラウンフィールド VCF ワークロードドメインと MetroCluster の導入手順

ブラウンフィールド展開とは、既存のvSphere環境があり、それをVCFワークロードドメインとしてインポートするシナリオです。

iSCSI、NVMe-oF、NFSv4.1 の場合は、vCenter（できれば ONTAP tools を使用）でセットアップし、その後 VCF Ops ツールを使用してワークロードドメインとしてインポートする必要があります。詳細については、link:https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/building-your-private-cloud-infrastructure/working-with-workload-domains/import-an-existing-vcenter-to-create-a-workload-domain.html["既存のvCenterをインポートしてワークロードドメインを作成する"]を参照してください。
