= VCF ワークロードドメイン内の vSphere ホストで NFS のネットワークを構成する
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
VMware Cloud Foundationワークロードドメイン内のvSphereホストでNFSネットワークを構成し、ONTAPストレージシステムへの接続を有効にします。VLAN分離による分散ポートグループを作成し、冗長性のためにアップリンクチーミングを構成し、各vSphereホストにVMkernelアダプタを設定して、フェイルオーバー機能のための専用NFSパスを確立します。

vSphere クライアントを使用して、ワークロードドメインクラスタで以下の手順を実行します。この場合、vCenter シングルサインオンが使用されているため、vSphere クライアントは管理ドメインとワークロードドメインの両方で共通です。



[[step-1-create-a-distributed-port-group-for-nfs-traffic]]
== ステップ1: NFSトラフィック用の分散ポートグループを作成する

NFS トラフィックを伝送するネットワークの新しい分散ポート グループを作成するには、次の手順を実行します。

.手順
. vSphere クライアントから、ワークロード ドメインの *インベントリ > ネットワーク* に移動します。既存の分散スイッチに移動し、*新しい分散ポート グループ...*を作成するアクションを選択します。
+
.例を表示
[%collapsible]
====
image:vmware-vcf-asa-022.png["新しいポートグループの作成を選択"]

====
. *新しい分散ポート グループ* ウィザードで、新しいポート グループの名前を入力し、*次へ* をクリックして続行します。
. *設定の構成*ページで、すべての設定を入力します。VLAN が使用されている場合は、正しい VLAN ID を必ず指定してください。続行するには、[次へ] をクリックします。
+
.例を表示
[%collapsible]
====
image:vmware-vcf-asa-023.png["VLAN IDを入力してください"]

====
. *完了準備完了*ページで変更を確認し、*完了*をクリックして新しい分散ポート グループを作成します。
. ポート グループが作成されたら、ポート グループに移動し、[設定の編集...] アクションを選択します。
+
.例を表示
[%collapsible]
====
image:vmware-vcf-aff-037.png["DPG - 設定の編集"]

====
. *分散ポート グループ - 設定の編集* ページで、左側のメニューの *チーミングとフェールオーバー* に移動します。NFS トラフィックに使用するアップリンクのチーミングを有効にするには、それらが *アクティブ アップリンク* 領域にまとめられていることを確認します。使用されていないアップリンクを「*未使用のアップリンク*」に移動します。
+
.例を表示
[%collapsible]
====
image:vmware-vcf-aff-038.png["DPG - チームアップリンク"]

====
. クラスター内の各 vSphere ホストについて、このプロセスを繰り返します。




[[step-2-create-a-vmkernel-adapter-on-each-vsphere-host]]
== ステップ 2：各 vSphere ホストに VMkernel アダプタを作成する

ワークロード ドメイン内の各 vSphere ホストに VMkernel アダプターを作成します。

.手順
. vSphere クライアントから、ワークロード ドメイン インベントリ内のいずれかの vSphere ホストに移動します。*設定* タブから *VMkernel アダプタ* を選択し、*ネットワークの追加…* をクリックして開始します。
+
.例を表示
[%collapsible]
====
image:vmware-vcf-asa-030.png["ネットワーク追加ウィザードを開始する"]

====
. *接続タイプの選択* ウィンドウで、*VMkernel ネットワーク アダプタ* を選択し、*次へ* をクリックして続行します。
+
.例を表示
[%collapsible]
====
image:vmware-vcf-asa-008.png["VMkernelネットワークアダプタを選択"]

====
. *ターゲット デバイスの選択* ページで、以前に作成した NFS の分散ポート グループの 1 つを選択します。
+
.例を表示
[%collapsible]
====
image:vmware-vcf-aff-039.png["ターゲットポートグループを選択"]

====
. *ポートのプロパティ*ページで、デフォルト（有効なサービスなし）のままにして、*次へ*をクリックして続行します。
. *IPv4 設定* ページで、*IP アドレス*、*サブネット マスク* を入力し、新しいゲートウェイ IP アドレスを指定します (必要な場合のみ)。続行するには、[次へ] をクリックします。
+
.例を表示
[%collapsible]
====
image:vmware-vcf-aff-040.png["VMkernel IPv4設定"]

====
. *完了準備完了*ページで選択内容を確認し、*完了*をクリックして VMkernel アダプタを作成します。
+
.例を表示
[%collapsible]
====
image:vmware-vcf-aff-041.png["VMkernelの選択を確認する"]

====
