= SnapMirror Active Sync（SANおよびNAS）を使用したVCF管理ドメイン用のストレッチクラスターの構成
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
このユースケースでは、 ONTAP tools for VMware vSphereを使用して、VCF 管理ドメインのストレッチ クラスタを構成する手順について説明します。この手順には、vSphere ホストと vCenter Server の展開、 ONTAPツールのインストール、 SnapMirror Active Sync によるデータストアの保護、保護されたデータストアへの VM の移行、および補足ストレージの構成が含まれます。

image:vmw-vcf-vmsc-mgmt-smas-001.png["VCF管理ドメイン用のONTAPを使用したストレッチクラスタ"]

SANでは、均一型と非均一型の両方のストレッチクラスタ構成がサポートされています。NASの場合、ONTAP 9.19.1でのアクティブ / パッシブ構成です。

[NOTE]
====
ホスト近接設定は、マルチパス構成と併用され、ストレージトラフィックに最適なパス選択を保証するために使用されます。ホスト近接設定は、SCSIの場合はigroupで、NVMe-oFの場合はサブシステムで構成されます。例えば、統一ホストアクセス構成では、ホストは拡張クラスタ内の両方のストレージシステムにアクセスできます。マルチパス構成では、最適なパスと最適ではないパスは、ホストの近接設定に基づいて構成されます。

====


[[scenario-overview]]
== シナリオの概要

ストレッチクラスタソリューションは、VCF管理ドメインまたはワークロードドメイン内のデフォルトクラスタ、あるいは追加クラスタに実装できます。ONTAP tools 10.6は、iSCSIおよびFCプロトコル上のVMFSデータストアに対して、SnapMirrorアクティブ同期によるデータストア保護をサポートしています。ONTAPは、SAN（iSCSI、FC、NVMe-oF対応）およびNAS（NFS v3およびNFSv4.1対応）に対してSnapMirrorアクティブ同期をサポートしています。SANプロトコルでは、保護は整合性グループレベルで実行されますが、NASではSVMレベルで実行されます。次の図は、FCを使用したVMFS向けONTAP tools for VMware vSphereを備えたVCF管理ドメインのストレッチクラスタソリューションを示しています。

image:vmware-vcf-asa-mgmt-stretchcluster-002.png["VCF管理ドメイン用のONTAPを使用したストレッチクラスタ"]

.管理ドメイン上の主ストレージ
[%collapsible%open]
====
. サポートされている任意のプロトコルを使用して、VCF管理ドメインをデプロイします。
+
.. FC および NFSv3 上の VMFS の場合、VCF インストーラーツールが直接使用されます。iSCSI、NVMe-oF、NFSv4.1 の場合は、vCenter で設定してから、VCF インストーラーツールを使用して管理ドメインをデプロイする必要があります。詳細については、link:vmw-vcf-migrate.html["iSCSI、NVMe-oF、およびNFSv4.1を使用したVCF管理ドメインの展開"] を参照してください。


. ONTAP tools for VMware vSphereを導入する
. VMware vSphere 用SnapCenterプラグインの導入 (オプション)
. データストアを保護します。
+
.. iSCSI および FC の場合、データストアを保護するには ONTAP tools 10.6 以降を使用します。NVMe-oF および NFSv4.1 の場合は、System Manager を使用してデータストアを保護してください。参考までに、NVMe/TCP と NFS に関するデモ動画を以下でご覧ください。




====
.管理ドメイン上の補助ストレージ
[%collapsible%open]
====
管理ドメインが起動して実行されたら、ONTAP tools 10.6以降を使用して追加のデータストアを作成し、iSCSIおよびFCのSnapMirrorアクティブ同期で保護することができます。NVMe-oFおよびNFSについては、以下のビデオデモをご参照ください。このデモはワークロードドメインで実行されていますが、管理ドメインでも同様の手順に従うことができます。

====
