[role="lead"]
VMware Cloud Foundation (VCF) 管理ドメインに補助ストレージとして iSCSI データストアを追加するための要件を確認します。



[[infrastructure-requirements]]
== インフラストラクチャ要件

次のコンポーネントと構成が適切であることを確認してください。

* ストレージ トラフィック専用のイーサネット スイッチ上に物理データ ポートを備えたONTAP AFFまたはASAストレージ システム。
* VCF管理ドメインの展開が完了し、vSphere Webクライアントにアクセスできます。




[[recommended-iscsi-network-design]]
== 推奨されるiSCSIネットワーク設計

iSCSI には完全に冗長化されたネットワーク設計を構成する必要があります。次の図は、ストレージ システム、スイッチ、ネットワーク アダプタ、およびホスト システムにフォールト トレランスを提供する冗長構成の例を示しています。NetAppを参照してくださいlink:https://docs.netapp.com/us-en/ontap/san-config/index.html["SAN構成に関するリファレンス"]追加情報については。

image:vmware-vcf-asa-074.png["iSCSIネットワーク設計"]{nbsp}

マルチパスおよび複数パス間のフェイルオーバーのために、iSCSI構成のすべてのSVMで、ストレージ ノードごとに別々のイーサネットネットワークに最低2つのLIFを作成してください。ONTAP 9.19.1以降では、AFF上のSVMで対称アクティブ / アクティブマルチパスオプションを有効にできます。ASAでは、対称アクティブ / アクティブマルチパスがデフォルトで有効になっています。


TIP: 同じ IP ネットワーク上に複数の VMkernel アダプタが構成されている状況では、ESXi ホスト上でソフトウェア iSCSI ポート バインディングを使用して、アダプタ間でロード バランシングが行われるようにすることを推奨します。KB 記事 link:https://knowledge.broadcom.com/external/article?legacyId=2038869["ソフトウェア iSCSI ポート バインディングの使用に関する考慮事項（vSphere）"^] を参照してください。
