= MetroClusterを使用して VCF 管理ドメインのストレッチ クラスタを構成する
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
このユースケースでは、FC、iSCSI、NVMe-oF、NFSv3、またはNFSv4.1をプライマリデータストアとして使用し、ONTAP MetroClusterを使用してVMware Cloud Foundation （VCF） 管理ドメイン用のストレッチクラスタを構成する手順を概説します。VCFは、お客様のニーズに基づいた柔軟な導入オプションを提供します。VCFインストーラーツールは、新しいVCF管理ドメインをデプロイするか、既存のvSphere環境をVCF管理ドメインに変換するために使用します。このドキュメントでは、MetroClusterの部分に焦点を当て、展開手順に基づいて他のドキュメントを参照します。

image:vmw-vcf-vmsc-mgmt-mcc-001.png["vMSC を使用した VCF 管理ドメイン、幅 = 500"]



[[introduction]]
== はじめに

このソリューションでは、ONTAP MetroClusterをプリンシパルデータストアとして使用したストレッチVCF管理ドメインの実装方法を説明します。MetroClusterを使用すると、ONTAPクラスタで実行されているすべてのワークロードに対して高可用性ソリューションをデプロイできます。ワークロードに特化した高可用性ソリューションを導入する必要がある場合は、SnapMirrorアクティブ同期（SANおよびNAS）の使用をご検討ください。SnapMirrorアクティブ同期（SAN）は整合性グループレベルで動作しますが、SnapMirrorアクティブ同期（NAS）はSVMレベルで動作します。詳細については、link:vmw-vcf-vmsc-mgmt-smas.html["SnapMirror Active Sync（SANおよびNAS）を使用したVCF管理ドメイン用のストレッチクラスターの構成"]を参照してください。



[[prerequisites]]
== 前提条件

このシナリオには、次のコンポーネントと構成が必要です。

* サポートされているONTAP MetroCluster構成
* ストレージ仮想マシン（SVM）は、優先ストレージ プロトコルで設定されています。
* ストレージトラフィックを伝送するために論理インターフェース（LIF）が作成され、SVMに関連付けられています。




[[high-level-overview]]
== 概要

MetroCluster は、集約レベルで処理されるワークロードに対して高可用性ソリューションを提供します。SVM は、MetroCluster のいずれかの障害ドメインでアクティブになります。

以下は、 MetroCluster構成を示す System Manager のサンプル スクリーンショットです。image:vmw-vcf-vmsc-mgmt-mcc-015.png["4ノードMetroClusterIP"]

image:vmw-vcf-vmsc-mgmt-mcc-014.png["障害ドメイン 2 からの SVM ネットワーク インターフェース"]

[注意] SVM はMetroCluster内の障害ドメインの 1 つでアクティブになります。

[[deployment-steps-for-greenfield-vcf-management-domain-with-metrocluster]]
== グリーンフィールドVCF管理ドメインと MetroCluster の展開手順

グリーンフィールド展開（既存のVCFコンポーネントがない新規展開）の場合、VCFインストーラーツールを使用して管理ドメインを展開します。このシナリオでは、FC上のVMFSおよびNFSv3がサポートされています。

VMFS on FC の場合、詳細については link:vmw-vcf-mgmt-principal-fc.html["VCF管理ドメインとFCベースのVMFSデータストアをONTAP上のプリンシパルストレージとして使用"] を参照してください。NFSv3 の場合、詳細については link:vmw-vcf-mgmt-principal-nfs.html["VCF管理ドメインとONTAP上のNFSv3データストアをプリンシパルストレージとして使用"] を参照してください。



[[deployment-steps-for-brownfield-vcf-management-domain-with-metrocluster]]
== ブラウンフィールドVCF管理ドメインとMetroClusterの展開手順

ブラウンフィールド展開とは、既存のvSphere環境をVCF管理ドメインとして統合するシナリオです。

iSCSI、NVMe-oF、NFSv4.1 の場合は、vCenter （できれば ONTAP tools を使用）で設定し、その後 VCF インストーラーツールを使用して管理ドメインに統合する必要があります。詳細については、link:vmw-vcf-mgmt-vmfs.html["vCenter と VMFS データストアの収束"] および link:vmw-vcf-mgmt-nfs.html["vCenter と NFS データストアの収束"] を参照してください。
