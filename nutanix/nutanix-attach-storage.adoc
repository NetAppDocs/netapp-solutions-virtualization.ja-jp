= ONTAP NFSストレージをNutanixコンピュートクラスタに接続する
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
ONTAPボリュームをプロビジョニングして接続を構成したら、Prism ElementまたはPrism Centralを使用して、ONTAP NFSボリュームをストレージコンテナとしてNutanixコンピューティングクラスタに接続します。

.開始する前に
以下の前提条件が満たされていることを確認してください：

* NutanixクラスターからONTAPクラスターまたはSVMにアクセスできます。
* 有効なONTAP管理用LIF（IPアドレスまたはFQDN）が利用可能です。
* 適切なONTAP認証情報が利用可能です。
* 必要なFlexVol、qtree、またはフォルダのエクスポートパスが作成され、NFSアクセス用に構成されています。


.手順
. Prism ElementのWebコンソールにログインします。
. メインメニューから、*ストレージ*を選択し、*+ 外部ストレージを接続*をクリックします。
. *初期設定*ページで、表示されている情報を確認し、*次へ*をクリックします。
+
image:nutanix-attach-001.png["外部ストレージ接続ウィザード、初期設定ページ"]

. *接続の詳細*ページで、外部ストレージベンダーとして*NetApp ONTAP*を選択し、次の値を入力します：
+
** *IPアドレス（IPv4）またはFQDN*：ONTAPクラスタまたはSVM管理LIFのアドレスまたはFQDNを入力します。
** *ユーザー名*：ONTAPサービスアカウントのユーザー名を入力してください。
** *パスワード*：サービスアカウントのパスワードを入力してください。
+
*Next*をクリックします。

+
image:nutanix-attach-002.png["外部ストレージ接続ウィザード、接続詳細ページ"]



. *ストレージの詳細*ページで、*外部ストレージ名*にONTAPストレージシステムの一意の名前を指定し、*エクスポートパス*に1つ以上のストレージエクスポートパスを入力してから、*追加*をクリックします。
+

NOTE: サポートされるエクスポートパスには、FlexVolおよびqtreeのエクスポートパスが含まれます。

+
image:nutanix-attach-003.png["外部ストレージ接続ウィザード、サービスボリュームのエクスポートパスの選択が表示されたストレージ詳細ページ"]

. *アタッチ*をクリックします。
+
システムはONTAPストレージをNutanixクラスタに接続します。Prism Elementの*Tasks*から、進捗状況やステータス情報を監視できます。

+
image:nutanix-attach-004.png["外部ストレージ接続ウィザード、選択したエクスポートパスとその容量が表示されたストレージ詳細ページ"]

+

NOTE:  `nconnect`オプションは、マウントオプションで使用されます。



[NOTE]
====
* 設定時に追加された最初のエクスポートパスは、自動的にデフォルトのストレージコンテナとして指定され、*Default Container*としてタグ付けされます。
* NetAppは、VMワークロードを分散して容量の使用率を平準化するために、ストレージコンテナとして複数のFlexVolボリュームを使用することを推奨しています。
* メタデータサービス（管理）には専用のボリュームを使用してください。
* エクスポートパスは、クラスタサービス（メタデータ）ボリュームまたはデフォルトのストレージコンテナに割り当てられていない限り、削除できます。
* Nutanixコンピューティングクラスタに接続されている間は、外部ストレージを取り外すことはできません。
* Nutanixコンピューティングクラスタには、ONTAP外部ストレージシステムを1つだけ接続できます。
* Nutanixは、ノードあたり最大128台のVM、最大32ノード、およびDRクラスタ間で最大4,800個のAOSでレプリケートされるvDisks（非同期レプリケーションと同期レプリケーションの組み合わせ）を推奨しています。


====
ストレージを接続したら、Nutanix Cloud Infrastructure（NCI）プラットフォーム上にPrism Centralをデプロイして、クラスタの管理および構成タスクを実行します。Prism Centralを介してONTAPストレージを接続することもできます。
