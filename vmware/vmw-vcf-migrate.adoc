= 既存のデータストアを持つvSphere環境をVCF管理ドメインに統合する方法について説明します
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
サポートされているすべてのvSphere環境は、VCF プライベートクラウド環境の一部として構築できます。VCF 管理ドメインに統合することも、ワークロードドメインとしてインポートすることも可能です。このソリューションでは、vSphereの既存の VMFS または NFS データストアが、クラスターを VCF 管理ドメインに変換するとプリンシパルストレージになる方法を示します。



[[solution-overview]]
== ソリューションの概要

このソリューションでは、クラスタがVCF管理ドメインに統合されたときに、vSphere内の既存のVMFSまたはNFSデータストアがプリンシパルストレージになる方法を示します。

このプロセスは、ONTAPストレージの堅牢性と柔軟性を活用して、シームレスなデータアクセスと管理を実現します。コンバージプロセスを通じてVCF管理ドメインが確立されると、管理者はVMFSとNFSの両方のデータストアを使用する環境を含む、追加のvSphere環境をVCFエコシステムに効率的にインポートできます。

この統合により、リソースの使用率が向上するだけでなく、プライベート クラウド インフラストラクチャの管理が簡素化され、既存のワークロードの中断を最小限に抑えながらスムーズな移行が可能になります。



[[architecture-overview]]
== アーキテクチャの概要

ONTAPツールのアーキテクチャは VMware 環境とシームレスに統合され、 ONTAPツール サービス、vSphere プラグイン、REST API を含むモジュール式のスケーラブルなフレームワークを活用して、効率的なストレージ管理、自動化、データ保護を実現します。

ONTAP tools for VMware vSphereは、 HA 構成または非 HA 構成のいずれにもインストールできます。
