= NFS データストアを使用した VCF 管理ドメインへの vCenter サーバインスタンス統合のデプロイメントワークフロー
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
既存のvSphereクラスターとNetApp ONTAP NFS データストアを VMware Cloud Foundation 管理ドメインに統合します。構成要件を確認し、ONTAP tools をデプロイして NFS データストアをプロビジョニングし、VCF インストーラーツールを使用して既存のコンポーネントを検証および活用し、必要な新しいコンポーネントをデプロイしてプラットフォームを構成します。

このワークフローは、ONTAP NFS 4.1データストアをVCF管理ドメインのプリンシパルストレージとして使用する場合にも適用されます。

統合プロセスの概要については、VMwareのドキュメントを参照してください： https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["既存の仮想インフラストラクチャをVCFに統合する"]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"]link:vmw-vcf-mgmt-nfs-requirements.html["構成要件を確認する"]
[role="quick-margin-para"]
NFS データストアを使用して vCenter サーバーインスタンスを VCF 管理ドメインに統合するための主要要件を確認します。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["2"]link:vmw-vcf-mgmt-nfs-deploy.html["ONTAPツールを導入し、NFSデータストアをプロビジョニングする"]
[role="quick-margin-para"]
ONTAP tools for VMware vSphereを導入し、NFS データストアをプロビジョニングします。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三つ"]link:vmw-vcf-mgmt-nfs-converge.html["vSphere クラスターを VCF 管理ドメインに統合する"]
[role="quick-margin-para"]
VCFインストーラーツールを使用して、VCF管理ドメインを構成する既存のコンポーネントを検証、再利用し、新しいコンポーネントをデプロイします。
