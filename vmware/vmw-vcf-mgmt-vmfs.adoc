= VMFSデータストアを使用したVCF管理ドメインへのvCenterサーバインスタンス統合のデプロイメントワークフロー
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
既存のvSphereクラスターとNetApp ONTAP VMFSデータストアをVMware Cloud Foundation管理ドメインに統合します。構成要件を確認し、ONTAP toolsをデプロイしてVMFSデータストアをプロビジョニングし、VCFインストーラーツールを使用して既存のコンポーネントを検証および活用し、必要な新しいコンポーネントをデプロイして、プラットフォームを構成します。

このワークフローは、サポートされているVMFSデータストアをVCF管理ドメインのプリンシパルストレージとして利用するためにも使用されます。

変換プロセスの概要については、VMwareのドキュメントを参照してください： https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["既存の仮想インフラストラクチャをVCFに統合する"]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"]link:vmw-vcf-mgmt-vmfs-requirements.html["構成要件を確認する"]
[role="quick-margin-para"]
VMFSデータストアを使用してvCenterサーバインスタンスをVCF管理ドメインに統合するための主要要件を確認します。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["2"]link:vmw-vcf-mgmt-vmfs-deploy.html["ONTAP tools の導入とサポート対象の VMFS データストアのプロビジョニング"]
[role="quick-margin-para"]
ONTAP tools for VMware vSphere を導入し、サポートされている VMFS データストアをプロビジョニングします。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三つ"]link:vmw-vcf-mgmt-vmfs-converge.html["vSphere クラスターを VCF 管理ドメインに統合する"]
[role="quick-margin-para"]
VCFインストーラーツールを使用して、VCF管理ドメインを構成する既存のコンポーネントを検証、再利用し、新しいコンポーネントをデプロイします。
